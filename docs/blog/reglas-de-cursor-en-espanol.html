Reglas de Cursor en español: cómo escribirlas y ejemplos listos

Por Macarena Arenas · 31 de octubre de 2026

Las reglas de Cursor son instrucciones permanentes que el agente lee antes de trabajar en tu proyecto. Bien escritas, evitan que la IA reescriba lo que ya funciona, invente cambios o te responda en inglés.

Dónde van las reglas

Las reglas de proyecto viven en la carpeta .cursor/rules/ de tu proyecto, como archivos con extensión .mdc. Un archivo .md normal en esa carpeta se ignora. Si prefieres Markdown simple, Cursor también lee un archivo AGENTS.md en la raíz.

tu-proyecto/
  .cursor/
    rules/
      01-no-reescribir.mdc
      02-seguridad.mdc
  AGENTS.md   (opcional)

Además existen las User Rules (en la configuración de Cursor, para todos tus proyectos) y las reglas de equipo.

Anatomía de una regla .mdc

Cada archivo tiene un encabezado (frontmatter) con tres campos y luego las instrucciones en Markdown:

  • description: de qué trata la regla. El agente la usa para decidir si la necesita.
  • globs: patrones de archivos (por ejemplo **/*.tsx). Si trabajas en un archivo que coincide, la regla se agrega sola.
  • alwaysApply: si es true, la regla se incluye en todas las conversaciones.

Si no pones ni descripción ni globs y alwaysApply es false, la regla solo se usa cuando la mencionas con @nombre-de-la-regla.

Ejemplo: regla para que la IA no reescriba tu proyecto

---
description: Cambios mínimos y sin reescrituras
alwaysApply: true
---

# Cambios mínimos
- Responde siempre en español, en simple.
- Haz solo el cambio pedido. No reescribas archivos completos
  ni cambies nombres, estilos o estructura que no te pedí.
- Antes de un cambio que toque más de 3 archivos, muéstrame
  el plan y espera mi aprobación.
- Nunca borres archivos sin preguntarme.
- Al terminar, dime qué cambiaste y cómo lo pruebo.

Consejos para escribir buenas reglas

  1. Una regla, un tema: separa "cambios mínimos", "seguridad", "pagos" e "interfaz en español" en archivos distintos.
  2. Frases concretas y verificables: "nunca uses NEXT_PUBLIC_ para claves secretas" funciona mejor que "sé seguro".
  3. Usa globs para reglas técnicas: la regla de pagos solo cuando trabajas en archivos de pagos.
  4. Cortas: si una regla crece demasiado, divídela.
  5. Versiónalas con Git para que todo tu equipo use las mismas.

Preguntas frecuentes

¿Dónde se guardan las reglas de Cursor?

En la carpeta .cursor/rules/ de tu proyecto, como archivos .mdc. También puedes usar AGENTS.md en la raíz o las User Rules en la configuración.

¿Sigue funcionando el archivo .cursorrules?

Es el formato antiguo. Hoy se recomienda usar archivos .mdc dentro de .cursor/rules/ o AGENTS.md.

¿Cómo hago que Cursor me responda en español?

Agrega una regla con alwaysApply: true que diga "Responde siempre en español" o ponlo en tus User Rules.
